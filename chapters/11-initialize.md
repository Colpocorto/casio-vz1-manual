# Initializing the VZ-1

| Scope | Procedure |
|---|---|
| **Everything** (factory reset) | Hold <kbd>WRITE</kbd> and switch power ON. Answer the "YES?" prompt with <kbd>YES</kbd>. All operation memories, voices and effect data return to factory presets (Appendix A) |
| **One Menu 1 function for one module** | <kbd>MENU 1</kbd> → select function → select module → hold <kbd>WRITE</kbd> and press <kbd>YES</kbd> (display: *COPY? SELECT M1–M8 / INIT? YES KEY*). Other functions are untouched |
| Menu 2, Normal functions 01–06 (all) | Hold <kbd>NORMAL</kbd> while pressing <kbd>MENU 2</kbd> |
| Menu 2, one function | <kbd>MENU 2</kbd> → function → hold <kbd>WRITE</kbd> → <kbd>YES</kbd> |
| Menu 2, Combination 01–17 (all) | Hold <kbd>MENU 2</kbd> and press <kbd>COMBINATION</kbd> |
| Menu 2, Multi Channel 01–06 and 18 (all areas) | Hold <kbd>MENU 2</kbd> and press <kbd>MULTI CHANNEL</kbd> |

!!! note "Coupled initializations"
    Initializing **1-00** resets line data of all modules. Initializing **1-09** also initializes AMP ENV in 1-17; **1-03** also initializes PITCH ENV in 1-17. In 1-17, each of the three pages can be initialized separately. Initialized (default) values: see Appendix A.
