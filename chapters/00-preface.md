# About this manual {.nonum}

This is a modern, restructured edition of the **CASIO VZ-1 Digital Synthesizer** owner's manual (original: 114 pages, iPD "Interactive Phase Distortion" sound source). It was rebuilt from a scan of the original; content is faithful to the source, but the order and teaching approach are new:

* **Task first** – a "how do I…" index, then concepts, then reference.
* **One reference format** – every function is documented as `Menu-Function` (e.g. **1-06** = Menu 1, function 06) with a one-line spec bar.
* **Figures are code** – all diagrams are generated from `figures/make_figures.py`.

!!! warning "Verify before trusting"
    Some values come from low-resolution scans. Anything uncertain is listed in **Open points & unreliable transcriptions** (last chapter). Check the original scan or the instrument when it matters.

## Conventions

| Notation | Meaning |
|---|---|
| <kbd>MENU 1</kbd> | A front-panel key |
| `00–99` | Range of values |
| **1-17** | Menu 1, function 17 (VELOCITY RATE) |
| *Domain* | Scope of a function's settings: **Global** (all modules), **Modular** (per module M1–M8), **Line** (per internal line), **Combined sounds** (per patch in a combination), **Area** (per MIDI area) |
| *Pages* | A function can have several display pages; step through them with the <kbd>MULTI AREA</kbd> keys |
| *Graphic* | Whether <kbd>DISPLAY</kbd> opens a graphic editor for that function |

## Reading paths

* **Just want sound:** Chapter 1 (Quick start).
* **Want to edit sounds:** Chapters 2 → 3 → 4 → 5 (tutorials), then the Menu 1 reference (chapter 6).
* **Performing / splitting / layering:** Chapter 9 (and chapter 10 for MIDI).
* **Never touched synthesis:** Chapter 12 (sound primer) first.
