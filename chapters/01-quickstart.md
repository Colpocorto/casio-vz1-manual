# Quick start

1. Put the VZ-1 on a stable stand. With the **power switch OFF**, connect the AC cord (correct voltage for your region).
2. Connect **MIX OUT** to an amplifier (not needed if you use headphones).
3. Set the VZ-1 **VOLUME** slider to MIN and the amp volume to MIN; switch the amp on.
4. Switch the VZ-1 on and raise both volumes.

{{fig:rear_panel|Rear panel connections (numbers match the list in chapter 4).}}

On power-up the first operation memory, **A-1 "SEE GOD"**, is selected. Operation memories are *combined* sounds of up to 4 patches, with effects and keyboard splits stored.

* Pick any of the 64 operation memories with the bank keys **A–H** and number keys **1–8** (the module ON/OFF row = banks, the module select row = numbers).
* Try **H-5 "BEAUTY/BEAST"**; play lightly, then heavily, then press a held key harder (after touch).
* Press <kbd>NORMAL</kbd> to hear single patches (the 64 internal sounds). Leads: **E-1…E-6**; brass/strings: bank **B**; basses: **D-1…D-4**.
* **Display brightness:** hold <kbd>DISPLAY</kbd> and move the **VALUE slider**.

The VZ-1 stores 64 internal patches and 64 operation memories; an optional card extends this (see *Memory map* in chapter 2).
