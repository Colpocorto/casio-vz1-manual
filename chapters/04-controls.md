## The menu system

The VZ-1 works like a small computer: choose a **mode**, then a **menu**, then a **function**, then edit its **parameters**.

1. Press a **mode key** (e.g. <kbd>NORMAL</kbd>).
2. Press a **menu key** (<kbd>MENU 1</kbd>…). The last function you used in that menu is recalled; the *function number flashes* (cursor is in the function-number position).
3. Select a function with the **value controls**.
4. Press the **same menu key again** to "access" the parameters; the cursor moves to the first parameter. (Graphic functions can skip this: press <kbd>DISPLAY</kbd> straight away.)
5. Move with the **cursor keys**, set values with the **slider** (approximate) and **value keys** (exact). Use <kbd>MULTI AREA</kbd> to turn display pages.
6. For modular functions, a **module number** is shown at the top right of the display; select another with a **module selector**.

To leave a function or mode, press any mode or menu key. From graphic editing, press <kbd>DISPLAY</kbd> again first, then a menu key. Press <kbd>COMPARE/RECALL</kbd> any time while editing to hear the original sound.

!!! tip "Function toggles"
    With the cursor on the function number, <kbd>CURSOR</kbd> toggles between related pairs **1-00 ↔ 1-09** and **2-01 ↔ 2-07**.

## Graphic editing

Functions marked *Graphic: yes* (1-03, 1-05, 1-06, 1-07, 1-09, 1-11, 1-12, 1-13, 1-16, 1-17, 2-13) show the parameter as a curve that redraws as you edit. Press <kbd>DISPLAY</kbd> (its LED lights) to enter; press it again to return to digital editing. The <kbd>MULTI AREA</kbd> keys **zoom** (×1/2 … ×4 for envelopes; ×1 … ×4 for cross-fade) and scroll with the cursor keys. In an envelope, <kbd>INTERNAL/SUSTAIN</kbd> sets/removes a sustain point (SS) and <kbd>CARD/END</kbd> sets/removes the end point (ED).
